# Automated Exam Seating Management System: Rules Reference

This document outlines the finalized rules governing how the system allocates students, manages room capacities, handles special accommodations, and coordinates invigilators.

---

## 1. Capacity and Seating Rules

### Rule 1: Room Capacity Rule

* [cite_start]The system must not allocate more examinees than the available capacity of a room, hall, block, or group[cite: 6].
* [cite_start]If the total student count exceeds total available seats, the system must show a capacity warning before final allocation[cite: 7].

### Rule 2: One Student - One Seat Rule

* [cite_start]Each student must be assigned only one seat[cite: 9].
* [cite_start]Similarly, one physical seat must not be assigned to more than one student[cite: 9].

---

## 2. Special Accommodation Rules

### Rule 3: Contagious Disease Isolation Rule

* [cite_start]Examinees suffering from contagious diseases must be allocated seats in a separate isolated location depending on their condition[cite: 11].
* [cite_start]Such students should not be placed in normal rooms with other examinees[cite: 12].

### Rule 4: Physical Disability and Amanuensis Rule

* [cite_start]Examinees who are blind or unable to write with their hands may be allowed to have a writing assistant[cite: 14].
* [cite_start]The system should allocate accessible seating and adjust room capacity to account for the extra person or required space[cite: 15].

---

## 3. Horizontal and Vertical Separation Rules

### Rule 5: Same Program Horizontal Separation Rule

* [cite_start]Students from the same program should not be seated side-by-side horizontally in the same row[cite: 17].
* [cite_start]*Example:* CE students should not be placed immediately beside other CE students where avoidable[cite: 18].

### Rule 6: Same Class/Semester Separation Rule

* [cite_start]Students from the same class or semester should not be seated side-by-side horizontally where possible[cite: 20].
* [cite_start]This rule supports fair examination conditions when students from the same academic group appear together[cite: 21].

### Rule 7: Consecutive Roll Number Horizontal Separation Rule

* [cite_start]Consecutive roll numbers must not be seated side-by-side horizontally[cite: 23].
* [cite_start]However, they may sit in front of or behind each other in the same column[cite: 23].
* [cite_start]*Example:* Roll 101 may sit behind Roll 102, but should not sit directly beside Roll 102[cite: 24].

### Rule 8: Same Program Vertical Arrangement Preference

* [cite_start]Students from the same program may preferably be arranged vertically in the same column[cite: 26].
* [cite_start]*Example:* CE students may be seated one behind another rather than beside each other[cite: 27].

### Rule 9: Different Program Same Department Rule

* [cite_start]Students may sometimes belong to the same broad department or faculty but different programs[cite: 29].
* [cite_start]*Example:* AI and CE may be connected to the same department, but they are different programs[cite: 30]. [cite_start]Therefore, AI students may sit beside CE students unless another rule is violated[cite: 31].

### Rule 10: Same Subject / Exam Group Separation Rule

* [cite_start]Students appearing for the same subject or same exam paper should not be seated side-by-side horizontally where possible[cite: 33].
* [cite_start]This is especially important when students from different programs are taking the same subject[cite: 33].

### Rule 11: Department/Program Distribution Rule

* [cite_start]The system should distribute students from the same program across columns, groups, rooms, or halls where possible[cite: 37].
* [cite_start]This ensures that one row or one side of the hall is not dominated by a single program[cite: 37].

## 4. Invigilator Management Rules

### Rule 12: Invigilator Minimum Rule

* [cite_start]Every examination room must have at least two invigilators assigned to it: one Chief Invigilator and one standard Invigilator, regardless of room size[cite: 39].

### Rule 13: Invigilator Capacity Ratio Rule

* [cite_start]As a general rule, the system should allocate one invigilator for every 10 examinees within a room[cite: 41].
* [cite_start]The final number of invigilators should be the higher value between two invigilators and the 1:10 ratio requirement[cite: 42].

---

## 5. Administrative Control

### Rule 14: Manual Override and Rule Warning Rule

* [cite_start]The system may allow manual editing or override by the administrator[cite: 44].
* [cite_start]However, if manual changes violate seating rules, the system should display a warning before saving the final arrangement[cite: 45].
